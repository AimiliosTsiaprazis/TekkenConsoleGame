# TekkenConsoleGame – C# OOP Console Game

## Description
TekkenConsoleGame is a console-based game inspired by Tekken, built using C# and object-oriented programming principles. Players select fighters with unique stats and moves, then engage in turn-based battles. The project demonstrates clean architecture, modular design, and practical OOP concepts.

## Features
- Multiple fighters with individual attributes: Health, AttackPower, Defense.
- Each fighter has multiple moves (Punch, Kick, Special) with varying damage.
- Turn-based combat system with damage and defense calculations.
- Interactive console gameplay.
- Modular architecture: Models, Repositories, Services, Controllers, Jobs.
